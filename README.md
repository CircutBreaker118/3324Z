# 3324Z — Circuit BreakerZ

Jekyll site for VEX robotics team **3324Z**. Live at [3324z.com](https://3324z.com) (GitHub Pages).

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Open [http://127.0.0.1:4000](http://127.0.0.1:4000). Navigation and site data live under `_data/`. Main styles are in `assets/css/site.css`.

## Build

```bash
bundle exec jekyll build
```

Output is written to `_site/`.
